# HolidayTruce

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
명절증후군은 매년 언론·맘카페에 반복 등장하는 검증된 페인포인트지만, 연 2회뿐인 이벤트라 대기업들이 거들떠보지 않는 사각지대 — 그 좁은 틈을 시댁 응대 스크립트와 일정·예산 조율 도구로 공략.

## Problem
명절마다 반복되는 시댁/처가 방문 일정 조율, 용돈·선물 예산 갈등, '며느리 우울증'으로 불리는 스트레스가 부부싸움과 이혼율 급증으로 이어지지만 이를 관리해주는 도구가 없고 정보는 커뮤니티에 파편화되어 있음.

## Target Users
기혼·신혼 커플, 특히 시댁 응대 스트레스를 겪는 30-40대 며느리/사위

## Core Features
1. AI 시댁·처가 응대 대화 스크립트 생성
2. 본가/처가 방문 일정 균형 체크 캘린더
3. 용돈·선물 예산 계산기 및 갈등 방지 체크리스트
4. 명절 후 감정소진도 기록과 다음 명절 대비 리포트

## Monetization
- Model: 시즌 결제(설·추석 연 2회) + 연중 가족행사 올인원 구독 확장
- Estimated MRR: $300-800
- Reasoning: 연 2회성 이벤트라 구독 유지가 구조적으로 어려워 시즌 원타임 결제 중심, 어버이날·생신 등으로 확장해야 월매출 방어 가능
